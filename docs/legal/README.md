# Documentos legais

A fonte única da política de privacidade vive dentro do backend, não aqui
— ver `backend/src/legal/politica-privacidade.md`. É servida em tempo de
execução pelo endpoint `GET /legal/privacy-policy`, para nunca haver duas
cópias a divergir.

Está aqui em `docs/legal/` só este apontador, para quem procura a partir
da documentação geral do projeto.
